# A 手像素画板 - 多人在线像素艺术协作平台

一个基于 Vue 3 + Vite 构建的实时协作像素画板应用，支持多用户同时在线创作像素艺术作品。

## ✨ 功能特性

- 🎨 **实时协作绘画** - 多用户同时在画布上放置像素，实时同步显示
- 🌈 **颜色选择器** - 提供丰富的颜色选择工具
- 🔍 **画布缩放** - 支持鼠标滚轮缩放和拖拽移动
- ⏱️ **冷却时间系统** - 防止滥用，限制放置频率（平均 2 次/秒）
- 📊 **数据统计展示** - 实时显示在线人数、累计访问人次、累计放置像素数
- 📱 **响应式设计** - 移动端自动缩放适配
- 🔄 **WebSocket 通信** - 实时双向通信，自动重连机制

## 🛠️ 技术栈

- **前端框架**: Vue 3 (Composition API)
- **构建工具**: Vite 7.x
- **通信协议**: WebSocket
- **渲染**: HTML5 Canvas

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

默认访问地址：`http://localhost:5173`

### 生产构建

```bash
npm run build
```

## 🎯 使用说明

1. **选择颜色** - 在左侧颜色选择器中选择喜欢的颜色
2. **放置像素** - 点击画布任意位置放置像素块
3. **缩放视图** - 使用鼠标滚轮放大/缩小画布
4. **移动画布** - 按住鼠标拖拽来移动画布
5. **重置视图** - 点击"重置视图"按钮恢复初始视角

## 📊 数据面板

右侧信息面板提供：

- **使用说明** - 快速了解操作方法
- **实时统计**：
  - 👥 在线人数
  - 👁️ 累计访问
  - 🎨 放置像素
- **绘画过程可视化** - Bilibili 视频链接

## 📝 注意事项

1. 放置像素有频率限制（平均 2 次/秒），触发后会进入冷却时间
2. 移动端会自动缩放整个应用以适应屏幕
3. 建议使用现代浏览器（Chrome、Firefox、Edge 等）
